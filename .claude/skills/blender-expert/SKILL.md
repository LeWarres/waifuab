# Blender expert (WaifuTren)

Models are **generated by Python scripts**, not hand-edited. Edit the script, rerun, commit the `.fbx`.

## Run
```
blender -b --python Tools/make_mechs.py                    # all -> Assets/Resources/Models/Enemy_<name>.fbx
blender -b --python Tools/make_mechs.py -- only a,b        # subset
blender -b --python Tools/make_mechs.py -- shot            # + contact sheet Tools/mechs_preview.png
```
Blender not on PATH here: use full path to `blender.exe`. Always `-b` (headless).

## Reuse first
- `Tools/lowpoly.py`: `reset()`, `box`, `cyl`, `ball`, `finish(name, paint=True)`, `render([...])`, FBX export. Import/copy its pattern; do not rewrite primitives.
- New asset = new `make_<thing>.py` modelled on closest sibling (`make_mechs`, `make_props`, `make_enemies`, `make_loco`, `make_stations`).

## FBX export (Unity) — keep identical to project
```
bpy.ops.export_scene.fbx(filepath=..., use_selection=True, object_types={"MESH"},
  axis_forward="-Z", axis_up="Y", bake_space_transform=True,
  apply_scale_options="FBX_SCALE_ALL", mesh_smooth_type="OFF"|"FACE", add_leaf_bones=False)
```
- Output only under `Assets/Resources/Models/` (loaded via `Resources.Load`).
- Print tris + dimensions after export (`print("MODEL", name, "tris", ...)`); check size in game units (1 BU = 1 m).

## Rules
- Low-poly, flat shading, vertex colors (`paint=True`), no textures unless required. Colors pre-darkened (gamma): preview with Gamma 1/2.2 node, as `shot` does.
- Modifier order: Mirror → Bevel → Subdiv → Triangulate; apply before export (FBX does not carry modifiers reliably).
- Apply scale/rotation (Ctrl+A) before export. Origin at feet/pivot used by game code.
- One mesh object per FBX; join parts, then export selection only.
- Ground/sky textures: `make_*_ground.py`, `gen_sky.py` write PNG to `Assets/Resources/Ground/`.

## Troubleshooting
| Symptom | Cause | Fix |
|---|---|---|
| Model rotated 90° in Unity | axis args | `axis_forward="-Z", axis_up="Y"`, `bake_space_transform=True` |
| Wrong size (100× / 0.01×) | scale not applied | `FBX_SCALE_ALL`, apply scale |
| Pink/white in Unity | materials/vertex color missing | `finish(..., paint=True)`; Unity material must read vertex colors |
| Dark or washed colors | gamma | colors pre-darkened; compare with `shot` sheet |
| Faceted vs smooth wrong | `mesh_smooth_type` | `"OFF"` flat, `"FACE"` face-smooth |
| Boolean fails / holes | non-manifold | Merge by distance, recalc normals, or build from primitives |
| Extra `_end` bones | leaf bones | `add_leaf_bones=False` |
| Stale model in game | not re-exported / Unity not refreshed | rerun script, focus Unity to reimport |

## Verify
Rerun with `-- shot`, view `Tools/mechs_preview.png`. Check tris budget and bounds in printed output. Do not commit scratch `.blend`.
